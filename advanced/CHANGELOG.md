# Changelog

## 0.1.0 — نسخه تحویل اولیه

- پیاده‌سازی shell واکنش‌گرا با React، TypeScript، Vite و Tailwind.
- پشتیبانی از Import/Export دقیق `transaction.json` مطابق نمونه docs.
- مدیریت Mapping خام مطابق `docs/mapping.json` با نسخه‌بندی SQLite.
- ساخت Payload کددار با engine مستقل، deterministic و تست‌پذیر.
- Mock API داخلی برای وضعیت‌های موفق، 400، 404، 500، timeout و network error.
- Audit کامل ارسال‌ها با وضعیت‌های pending، success، failed و cancelled.
- مدیریت Templateها با ذخیره، بارگذاری، Import/Export و seed پیش‌فرض.
- تست‌های واحد، کامپوننتی، معماری و یکپارچه با Vitest.
- مستندات نهایی کاربر، API، Mapping و Troubleshooting.
