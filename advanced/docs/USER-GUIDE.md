# راهنمای کاربر FraudTransactionForge

## شروع سریع

1. برنامه را با `npm run dev` اجرا کنید.
2. از منوی راست وارد «میز کار» شوید.
3. JSON تراکنش را فقط با ساختار `mainTransaction.attrsList` وارد یا paste کنید.
4. روی «اعتبارسنجی/ساخت Payload» بزنید و پیام‌های فارسی را بررسی کنید.
5. در صورت صحیح بودن Payload، دکمه ارسال تراکنش را بزنید.

## میز کار

- فرم Header شامل `fraudMessageId`، `sysName` و `businessId` است.
- هر ردیف `attrsList` یک leg تراکنش است.
- برای مقادیر خالی، Payload مقدار `""` تولید می‌کند.
- خروجی JSON با `dir="ltr"` نمایش داده می‌شود تا اعداد و کلیدها درست خوانده شوند.

## کدینگ Mapping

- Mapping دقیقاً object خام `code -> sourceField` است.
- فایل Mapping نباید metadata، version، fields یا توضیح اضافه داشته باشد.
- کدهای مجاز از `951` تا `1000` هستند و تعداد کلیدها باید ۵۰ باشد.
- هر کد فقط به یک فیلد منبع وصل می‌شود.

## ارسال و تاریخچه

- در حالت Mock، درخواست شبکه واقعی ارسال نمی‌شود.
- هر ارسال ابتدا در Audit با وضعیت `pending` ثبت می‌شود.
- پس از پاسخ، رکورد به `success`، `failed` یا `cancelled` تغییر می‌کند.
- از صفحه تاریخچه می‌توانید جزئیات را ببینید یا تراکنش قبلی را Replay کنید.

## قالب‌ها

- از میز کار می‌توانید تراکنش فعلی را به‌عنوان Template ذخیره کنید.
- نام Template تکراری پذیرفته نمی‌شود.
- قالب‌های پیش‌فرض برای سناریوهای رایج از قبل آماده‌اند.

## تست دستی پیشنهادی

- Breakpointهای `320`، `375`، `768`، `1024`، `1440` و `1920` پیکسل را بررسی کنید.
- کل برنامه را فقط با کیبورد طی کنید.
- Skip Link ابتدای صفحه را با Tab فعال کنید.
- یک سناریوی موفق و یک سناریوی `server-error` را از Mock API اجرا کنید.
